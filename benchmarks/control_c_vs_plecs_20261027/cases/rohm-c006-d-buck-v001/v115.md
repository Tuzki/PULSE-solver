# PULSE Netlist v1.1

All electrical values and stored initial states are retained. Ideal blocking is
regularized by 1 Gohm off resistance; diode I-V is continuous at Vf.
Thermal XML lookup losses and thermal displays are not implemented by this netlist.
No zero-valued electrical resistor is present in the source; no added parasitic
capacitance is used. Gate resistances in the source are thermal loss-table inputs,
not electrical gate-network resistors.
