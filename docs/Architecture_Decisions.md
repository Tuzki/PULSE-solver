# V1.15 架构决策

当前规范为 Engineering_Contract.md，继承的 V1.1 文档用于语言、接口和历史来源，
其中全历史认证要求不再作为本产品运行主路径的接受条件。

- 保留 Markdown v1.1 文法、13 原语、SUBCKT、REAL/BOOL/TRIG、q/phi/eta 状态、
  联合 Descriptor/MNA、T128、C ABI1/2、PEWave V1。没有增加新红色原语。
- 正式核心为原生 C++20；Python仅是测试/报告工具。
- 默认原子时间10fs，与保存间隔独立；显式旧 atom-exponent 保留旧接口行为。
- 状态传播采用平衡后的数值模态矩阵指数。缺陷特征向量系统使用矩阵指数后备。
  近重根的标量指数项先合并局部Taylor系数，避免独立取绝对值造成虚假搜索膨胀。
- 事件定位针对当前数值点轨迹，分别求首次有向交叉，再形成单一锚定候选窗口。
  不继承全历史状态包络，也不枚举窗口内所有中间模态组合。
- 窗内候选可以因新模态导数反向而取消；首个事件不得换模后立即反向。
- 普通无事件、静止器件不因导数零而报错；已定位事件若导数为零，或不能在原子
  时间内从求值噪声中分辨，就在提交前停止。
- 初始模态采用点值/方向迭代，循环或预算耗尽拒绝；不声称搜索所有初始固定点
  或证明任意代数反馈电路的全局唯一性。模型需有明确、正则的初始化。
- 普通连续换模只修改候选段。REG变化时重新判定受离散跳变影响的CMP/PWA R，
  保留数字控制所需的代数重算。其余不能解释的代数阈值跳变在提交前拒绝。
- 同刻REG、延时均读取同一旧快照；微步骤不推进物理时间；队列、状态、日志
  整体事务提交，异常回滚到上一提交点。
- Coss/Cj或有限电流坡段由网表表达。primitive SW仍为有限Ron/Roff；不自动赋予
  任意器件物理开关时间、迟滞、雪崩、反向恢复或最短翻转间隔。
- 旧首次根数学库保留作兼容/参考代码；新Runtime不调用它。旧继承包络认证核心
  和相关验收源代码归档在validation/v1_1，不进入新Runtime。
- 完成性、数值传播误差、事件时间估计、模型等价和PLECS校准分别记录。
  COMPLETED和高精度定时轨迹复核均不等于完整物理正确性认证。
