# Legacy migration notes

Generated by `python3 scripts/migrate_legacy.py --check`.

These are eight read-only source models and nine Markdown fixtures, including a separate LLC 100-cycle request. The migration preserves constitutive equations and specified initial conditions. This is a structural equivalence statement, not a successful simulation, numerical-error, or performance claim.

## Audited semantics

- V1.0 `src/model.cpp`: C/V default ESR=1u Ω; L default ESR=0; D defaults VON=.7 V, RDON=.03 Ω, RDOFF=1Meg Ω; S defaults RDON=.02 Ω and RDOFF=1Meg Ω. Explicit values take precedence.
- Every nonzero ESR becomes a positive series R and the ideal two-terminal original primitive. C IC is the internal capacitor voltage; L IC is winding current, both preserved. Source polarity and branch-current reference remain first node toward second node.
- Each legacy D gets its own SUBCKT and uniquely named frozen global parameters. SENSOR measures V(A)-V(K); CMP GE VON chooses SW conductance and SEL chooses current offset. Off: i=v/RDOFF. On: i=v/RDON-VON/RDON. No hidden diode Kind, no omitted leakage, no ideal-diode approximation.
- The old diode law is discontinuous by VON/RDOFF at its threshold. It therefore cannot be encoded as one continuous IV_TABLE without changing the model. V1.0 uses voltage-minus-VON for turn-on and minus-current for turn-off guards, with numeric tolerances. New GE selects the exact voltage boundary; historical-side/tolerance behavior at an exactly marginal boundary is not proven identical. C02 may safely stop there. Structural equivalence applies away from this unresolved equality convention.
- V1.0 `src/schedule.cpp` defines PWM true when local=(t-phase) mod T is less than width=duty*T-deadtime. The fixture initializes phase-zero gates high (REG IC=1), delayed gates low (IC=0), generates periodic ON at phase and transport OFF after width. The t=0 ON notification repeats the same gate value. Old GATE statement IDs and switch gate references are joined by the declared output name (G1/G2/GA/GB), not by GATE1/GATE2 IDs.
- V1.0 `src/model.cpp` defines mutual M=sign*K*sqrt(L1*L2), with default dots at each first node. LLC uses ordered L_MATRIX PORT 1=L1, PORT 2=L2 and retains each winding ESR externally. Internal single-branch winding current SENSORs expose both directions explicitly; diode composite current requires summing SW_PATH and I_OFFSET.
- LLC REF1 N1 and REF2 N9 both map to 0. V1.0 treats both named references as ground. The primary and secondary are separate galvanic islands coupled magnetically; choosing each island reference as zero preserves within-island voltages, branch currents and magnetic coupling. No electrical wire between nonreference terminals is introduced. Cross-island absolute potential has no independent physical meaning; the old fixed reference convention is retained.
- Short switched fixtures request five 100kHz periods (50us). LLC_100cycles requests 1ms. Linear RC requests 1ms; linear RLC requests 5s. These are explicit regression windows, not inherited CLI/API durations from V1.0. Output registry names change under explicit ESR/SUBCKT expansion; observations must use the mapping below.
