# PULSE Stage D1 与 PLECS：ROHM 案例简洁对比报告

日期：2026-11-04。D1 求解器版本：`05fb315`，Linux Release；PLECS 4.8.2 在同机 Windows 运行，每例实测一次。

20 例中，19 例有 PULSE 输入：**10 例完整交付、9 例失败，另 1 例未转换**。完整交付的 10 例中，D1 **8 例更快、2 例更慢**。

## 比较口径

- 用时：发起仿真至完成通知，包含 D1 启动、计算、事件归档及写文件；PLECS 使用 simulate RPC 返回时间。排除模型加载、控制模块编译、WSL 启动和波形重建。
- 精度：完整原始 1 µs 参考网格，阈值为各通道 `atol + 1% × |PLECS|`，不移动时轴、不剔除边沿。
- “统计通过”检查各通道均值、RMS、最大值；“逐点通过率”为满足阈值的通道采样值比例，**不等同于统一相对误差或连续时间精度**。
