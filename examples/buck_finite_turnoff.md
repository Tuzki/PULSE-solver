# PULSE Netlist v1.1

V1.15 finite turn-off demonstration. Positive channel current falls at a fixed
maximum slope after OFF, while Coss/Cj supply commutation dynamics. This is a
restricted affine SUBCKT model, not a full MOS gate-charge/avalanche model.

## Parameters
```pulse
.PARAM VIN=24
.PARAM RON=20m
.PARAM ROFF=1Meg
.PARAM FALL_RATE=500Meg
.PARAM COSS=1n
.PARAM CJ=100p
```

## Network
```pulse
.SUBCKT MOS_FINITE D S GATE OFF
SW_CHANNEL D S GATE RON={RON} ROFF={ROFF}
SENSOR_V VDS V D S
SENSOR_I ICH I SW_CHANNEL
MATH_SAMPLE SAMPLED_I = ICH - (1/{ROFF})*VDS
REG_I I_OFF SAMPLED_I OFF IC=0
INT_CLOCK CLOCK 1 IC=0
REG_T T_OFF CLOCK OFF IC=0
MATH_RAMP I_RAMP = I_OFF - {FALL_RATE}*(CLOCK-T_OFF)
CMP_POS POS I_RAMP OP=GT THRESHOLD=0
SEL_ACTIVE ACTIVE GATE POS 0
SEL_CURRENT I_FALL ACTIVE 0 I_RAMP
I_FALL_PATH D S I_FALL
C_OSS D S C={COSS} IC_V=0
.ENDS MOS_FINITE

.SUBCKT DIODE A K
SENSOR_V VD V A K
CMP_ON ON VD OP=GE THRESHOLD=.5
SW_PATH A K ON RON=.1 ROFF=1Meg
MATH_ZERO ZERO = 0
MATH_BIAS BIAS = -5
SEL_OFFSET OFFSET ON ZERO BIAS
I_OFFSET A K OFFSET
C_J A K C={CJ} IC_V={-VIN}
.ENDS DIODE

V_IN VIN 0 DC={VIN}
X_MOS VIN SW GATE OFF MOS_FINITE
X_D 0 SW DIODE
L_OUT SW OUT L=100u IC_I=5
C_OUT OUT 0 C=20u IC_V=12
R_LOAD OUT 0 R=2.4
EVENT_OFF OFF MODE=AT AT=2u
EVENT_LATER ON MODE=AT AT=10u
REG_GATE GATE MODE=SR SET=ON RESET=OFF PRIORITY=RESET IC=1
EVENT_FALL_END FALL_END MODE=EDGE SOURCE=X_MOS/POS EDGE=FALL
EVENT_D_ON D_ON MODE=EDGE SOURCE=X_D/ON EDGE=RISE
```

## Simulation
```pulse
.TRAN T_END=5u SAVE_DT=1n
.SAVE V(SW) V(OUT) I(L_OUT) X_MOS/I_FALL X_MOS/ACTIVE X_D/ON OFF FALL_END D_ON
```
