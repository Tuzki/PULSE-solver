# PULSE Netlist v1.1

RC PWM vertical example, including a continuous SUBCKT low-pass, sampled
power, dynamic delay, algebraic sensing and event-driven switch control.

## Parameters
```pulse
.PARAM VIN=10
.PARAM VREF=20
.PARAM TS=100u
.PARAM RLOAD=10
.PARAM COUT=100u
```

## Network
```pulse
.SUBCKT LOWPASS INPUT OUTPUT
MATH_D DX = 1000*(INPUT-OUTPUT)
INT_F OUTPUT DX IC=0
.ENDS LOWPASS
V_IN VIN 0 DC={VIN}
SW_MAIN VIN VOUT GATE RON=10m ROFF=1Meg
R_LOAD VOUT 0 R={RLOAD}
C_OUT VOUT 0 C={COUT} IC_V=0
SENSOR_V VS V VOUT 0
SENSOR_I IL I R_LOAD
X_FILTER VS VF LOWPASS
MATH_ERROR ERROR = {VREF}-VF
CMP_HIGH HIGH VF OP=GE THRESHOLD={VREF}
EVENT_EDGE RISE MODE=EDGE SOURCE=HIGH EDGE=RISE
EVENT_CLK CLK MODE=PERIODIC START=0 PERIOD={TS}
MATH_DUTY DUTY_NEW = .6
REG_DUTY DUTY DUTY_NEW CLK IC=.4
MATH_TON TON = {TS}*DUTY
EVENT_OFF OFF MODE=DELAY SOURCE=CLK DELAY_INPUT=TON POLICY=REPLACE
REG_GATE GATE MODE=SR SET=CLK RESET=OFF PRIORITY=RESET IC=0
REG_V VSAMP VS CLK IC=0
REG_I ISAMP IL CLK IC=0
MATH_POWER POWER VSAMP ISAMP OP=MUL
```
