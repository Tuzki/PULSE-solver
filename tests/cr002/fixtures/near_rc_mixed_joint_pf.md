# PULSE Netlist v1.1

CR-002 mixed near-threshold fixture: D1 starts ON and turns OFF while D2 starts
OFF and turns ON in the same engineering window. Explicit 1 pF Cj each.

## Parameters
```pulse
.PARAM NR_D1_VON=.5
.PARAM NR_D1_RON=.1
.PARAM NR_D1_ROFF=1Meg
.PARAM NR_D2_VON=.500000001
.PARAM NR_D2_RON=.1
.PARAM NR_D2_ROFF=1Meg
.PARAM CR002_CJ=1p
```

## Network
```pulse
.SUBCKT NR_D1 A K
SENSOR_V VD V A K
CMP_ON ON VD OP=GE THRESHOLD={NR_D1_VON}
SW_PATH A K ON RON={NR_D1_RON} ROFF={NR_D1_ROFF}
MATH_ZERO ZERO = 0
MATH_BIAS BIAS = {-NR_D1_VON/NR_D1_RON}
SEL_OFFSET OFFSET ON ZERO BIAS
I_OFFSET A K OFFSET
.ENDS NR_D1
.SUBCKT NR_D2 A K
SENSOR_V VD V A K
CMP_ON ON VD OP=GE THRESHOLD={NR_D2_VON}
SW_PATH A K ON RON={NR_D2_RON} ROFF={NR_D2_ROFF}
MATH_ZERO ZERO = 0
MATH_BIAS BIAS = {-NR_D2_VON/NR_D2_RON}
SEL_OFFSET OFFSET ON ZERO BIAS
I_OFFSET A K OFFSET
.ENDS NR_D2
R1 a 0 R=1k
C1 a 0 C=1n IC_V=2
C_NEAR_D1 a 0 C={CR002_CJ} IC_V=2
X_D1 a 0 NR_D1
VDC2 in 0 DC=1
R2 in b R=1k
C2 b 0 C=.48797p IC_V=0
C_NEAR_D2 b 0 C={CR002_CJ} IC_V=0
X_D2 b 0 NR_D2
```

## Simulation

```pulse
.TRAN T_END=2.0000000000000002e-03 SAVE_DT=1.0000000000000000e-05
```
